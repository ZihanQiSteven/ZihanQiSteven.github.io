rclone privacy policy

For the personal Google Drive OAuth application maintained by Zihan Qi (Steven).

Effective date: 8 October 2026

本政策适用于 Steven 在自己的设备上运行 rclone 的个人 Google Drive OAuth 配置，不适用于面向其他用户的托管服务。

1. Scope and purpose

This application is used only by me, on my own devices, to manage, transfer, synchronize, and back up my own Google Drive files using rclone. This website provides public application information and this policy; it does not operate rclone on behalf of visitors.

2. Google data accessed

Subject to the OAuth scopes granted and the commands executed, rclone can access Google Drive file and folder names, IDs, paths, sizes, timestamps, and other metadata returned by the Drive API. It can access file contents when downloading, uploading, copying, or synchronizing files, and may modify or delete files when instructed.

OAuth access and refresh tokens are used to authorize these operations. The exact permissions are shown on Google’s consent screen. Access does not mean that every file is automatically downloaded; processing depends on the commands and configuration used.

3. How data is used

Google Drive data is used to carry out the file operations I request. It is not used by this application for advertising, sale of personal information, or training generalized artificial intelligence or machine-learning models. The application’s use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

4. Storage and protection

rclone runs locally. Authorization tokens are kept in the local rclone configuration according to its settings. Downloaded files, caches, and logs may be stored on my devices according to the commands and settings I use. Configuration encryption is an optional rclone setting; this policy does not claim it is enabled.

Access to local data is controlled through my device and file permissions. Google API communications use HTTPS. Tokens and client secrets should not be published in this website repository. This static website does not receive or store Google Drive file contents or OAuth tokens.

5. Sharing and transfers

This application does not sell Google user data or share it for advertising. File contents are transferred to my device or to a destination I explicitly select in a rclone command, which may be another configured storage provider. Such transfers follow my instructions and the destination provider’s own terms and privacy policy.

The website is published using GitHub Pages with a custom domain. Its hosting infrastructure may process ordinary website request information, such as IP addresses, under GitHub’s privacy statement. This is separate from rclone’s Google Drive access.

6. Retention, deletion, and revocation

Local copies, caches, configuration files, and logs remain until I delete them or until configured cleanup occurs. Files copied to another storage destination remain subject to that destination’s retention settings. This application has no central server holding users’ Drive data.

I can revoke the app’s Google access through Google Account connections, then remove the corresponding local rclone configuration and tokens. Revoking access does not automatically delete files already downloaded or transferred; those copies must be deleted separately.

7. Changes and contact

This policy will be updated if the application’s data practices change. The current configuration is for personal use only; any future service for other users would require updated disclosures reflecting that service.

Maintainer: Zihan Qi (Steven). For questions about this policy, use the contact options on my GitHub profile. Do not post OAuth tokens or private file contents publicly.
