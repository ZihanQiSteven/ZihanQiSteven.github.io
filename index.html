What this application does

This OAuth application lets me authorize rclone running on my own devices to access my own Google Drive. I use it to manage files and perform transfers, synchronization, and backups that I explicitly initiate.

It is a personal configuration of the open-source rclone tool, maintained by Zihan Qi (Steven). This website is not the official rclone website and does not offer a hosted file-management service or public registration.

Why Google Drive access is needed

Depending on the permissions I grant and the commands I run, rclone may list files and folders, read file metadata, download files, upload files, and modify or delete files. This access is needed to perform the requested file-management and synchronization operations.

OAuth authorization tokens and the rclone configuration are handled on my own devices. This static website has no Google sign-in flow, file upload form, or backend that receives Drive files or OAuth tokens.

Google authorization is performed through rclone and Google’s consent screen. Do not submit tokens, client secrets, or private files to this website or its GitHub repository.
